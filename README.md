# NihoVoca Privacy Policy (GitHub Pages)

Static privacy policy pages for the NihoVoca app.

## Pages

| File | Language |
|------|----------|
| [index.html](./index.html) | Language hub |
| [zh.html](./zh.html) | 繁體中文隱私權政策 |
| [en.html](./en.html) | English privacy policy |
| [delete-zh.html](./delete-zh.html) | 繁體中文刪除資料說明 |
| [delete-en.html](./delete-en.html) | English data deletion |

## Enable GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch `main` (or `master`) and folder **/ (root)**.
5. Save. After a few minutes, the site is available at  
   `https://<user-or-org>.github.io/<repo>/`.

## URLs for Google Play

Use the published URLs, for example:

- Privacy (zh): `https://<user-or-org>.github.io/privacy/zh.html`
- Privacy (en): `https://<user-or-org>.github.io/privacy/en.html`
- **Account / data deletion (Play Console)**: `https://<user-or-org>.github.io/privacy/delete-zh.html`
- Data deletion (en): `https://<user-or-org>.github.io/privacy/delete-en.html`

Replace `<user-or-org>` and repo name with your actual GitHub Pages URL.

## Customize

- Update the effective date in `zh.html` and `en.html` when you change the policy.
- Add a support email in section 11 after you set it in Play Console.
